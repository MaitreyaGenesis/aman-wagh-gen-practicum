## Project Overview

This application integrates with HubSpot CRM using a Private App and displays Book custom object records. Users can create new Book records through a form and view all records on the homepage.

## Features

- View all Books records from HubSpot
- Create new Books records
- Display data using Pug templates
- Connect to HubSpot using a Private App
